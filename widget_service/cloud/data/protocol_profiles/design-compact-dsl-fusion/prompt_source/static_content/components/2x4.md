# 宽卡专用组件

| 名称 | 适用条件 | 承载内容 | 使用边界 |
|---|---|---|---|
| ComparisonGroup | 真正等权且短的对比 | 主读数、对象名、短细节 | 仅2x4，2–3个对象 |

## ComparisonGroup

### 选择条件

短且等权对比才使用；非必要不要强制三栏，不能为做三栏而新增、删除对象。
价格放primaryText，完整单位不拆；对象名放secondaryText。长值改全宽记录或属性表。

### 参数与容量

| 参数 | 类型 / 可选值 | 要求 |
|---|---|---|
| items | 2–3项{primaryText,secondaryText?,details?} | primaryText必填 |
| items[].details | 1–2条短文字 | 可选辅助内容 |
| fontSize | 12 / 11 / 10 | 沿用正文文字档位，主值保留原有层级 |
