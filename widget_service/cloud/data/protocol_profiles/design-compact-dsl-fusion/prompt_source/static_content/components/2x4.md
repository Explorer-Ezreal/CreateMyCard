# 对比组件

## 总表
| 组件 | 适用条件 | 承载内容 | 使用边界 |
|---|---|---|---|
| ComparisonGroup | 两到四个对象按相近维度比较 | items[].primaryText、secondaryText、details | 仅2x4；四项仅用于无标题2×2宫格 |

## ComparisonGroup
### 选择条件
对象具有可比较的读数、条件或方案；各栏对象与字段层级一致。长叙述优先全宽列表。
两到三项沿横向等权排列；恰好四项且不需要公共标题时使用2×2宫格，不为凑满四格拆分对象。
### 语义字段
items为2–4项；primaryText必填，secondaryText可选，details为可选1–2条辅助文字。
对象名称和数值须在各自栏内可读，不用其它栏或共同标题代替本栏名称。
### Runtime规则
两到三项使用等宽横排背板、8vp栏间距。四项使用2×2宫格，横纵间距12vp，单格宽度随正文区
自适应；参考画布下为132×57vp。四项整体占满126vp正文高度，不能同时使用SingleLineTitle。
所有背板保持8vp内边距、12vp圆角、固定文字层级和等高；单格文字放不下时精简Plan表达，不能缩字。
### 示例
```genui
["body","ComparisonGroup",{"items":[{"primaryText":"128元/月","secondaryText":"甲方案","details":["30GB"]},{"primaryText":"159元/月","secondaryText":"乙方案","details":["60GB"]}]}]
```
