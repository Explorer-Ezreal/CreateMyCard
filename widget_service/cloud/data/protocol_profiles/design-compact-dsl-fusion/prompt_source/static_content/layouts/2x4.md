# 宽卡布局

| 名称 | 适用条件 | 承载内容 / 角色 | 使用边界 |
|---|---|---|---|
| W-static-content | 无动作正文 | header?、body、note? | body为ContentBlock、RecordList或ComparisonGroup |
| W-split-panels | 有Action的正文 | title-content-action Region及合法内容区域 | 沿用登记分区合同 |
| W-four-slots | 纯四动作 | 四个CardButton | 四槽全部为CardButton，不承载静态正文 |
