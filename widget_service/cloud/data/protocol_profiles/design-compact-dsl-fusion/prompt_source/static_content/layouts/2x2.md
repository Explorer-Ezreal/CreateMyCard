# 小卡布局

| 名称 | 适用条件 | 承载内容 / 角色 | 使用边界 |
|---|---|---|---|
| S-static-content | 无动作正文 | header?、body、note? | body为ContentBlock或RecordList |
| S-title-content-action | 单动作 | title、content、action | 标准内容与动作结构 |
| S-content-dual-action | 双动作 | 内容与两个固定动作 | 沿用已登记双动作合同 |

当已接受Plan恰好只有一个Action、至多一个明确标题事实、没有正文/dataId展示事实时，
必须使用S-title-content-action的variant:"title-action"，children恰好为[title,action]。
title是稳定的SingleLineTitle，action是带完整handler的PillButton。
不得为看起来更完整而补造ContentBlock、SecondaryBody、说明性正文或空内容槽；
只要Plan存在任一正文或dataId展示事实，即回到标准[title,content,action]结构并完整展示该事实。
